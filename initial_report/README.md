# Initial Report Package

Start here:

1. Open `trainfo_initial_data_report.md` for the written data-wrangling section and current findings.
2. Open `trainfo_data_quality_by_crossing.csv` for the crossing-by-crossing audit.
3. Use `trainfo_8streets_events_clean.csv` for the eight requested streets.
4. Use `trainfo_all_events_clean.csv` for all crossings with usable event records.

The cleaned CSV files remove exact duplicate events and invalid/nonpositive durations. They also include calculated blockage end date/time fields. The original raw downloads and merged source files remain in the parent workspace folder and were not changed.
